Five forms are built this way: EmONC CTF, Newborn CTF, MoH SAC, and the two Knowledge Assessments — all from the same generated sheets.
Counties, facility selects and the cascade are derived from the generated facility list — so a new county can never be missing from the form.

Validate — what Kobo would reject

✓
Every select has choices no “List name not in choices sheet”
✓
No duplicate question names
✓
Expressions balanced parentheses & quotes, ignoring quoted text
✓
No unreachable comparisons every ${field} = 'value' matches a real choice
This is the check that catches the silent bug. With the old “Refferal” spelling the comparison could never be true — Kobo deploys it happily and the mentee list simply never opens.
