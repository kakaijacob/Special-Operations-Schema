Validate — what Kobo would reject

✓
Every select has choices no “List name not in choices sheet”
✓
No duplicate question names
✓
Expressions balanced parentheses & quotes, ignoring quoted text
✓
No unreachable comparisons every ${field} = 'value' matches a real choice
This catches the silent bug. With the old “Refferal” spelling the comparison could never be true — Kobo deploys it and the mentee list simply never opens.
